# Soundfonts (MIDI → MP3)

- `TimGM6mb.sf2` — General MIDI bank (~5.7 MB) used by the browser MIDI→MP3 converter in the Drive matcher.
- Source: [pretty-midi](https://github.com/craffel/pretty-midi) (`pretty_midi/TimGM6mb.sf2`), GPL-compatible TimGM6mb soundfont.
- Loaded lazily on first MIDI conversion (`/soundfonts/TimGM6mb.sf2`); cached in memory for the session.
