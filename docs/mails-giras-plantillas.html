Para PDF: «Imprimir / PDF» o Ctrl+P → Guardar como PDF.

Cómo devolver feedback
  1. Leé cada tarjeta: el asunto (arriba) y el cuerpo (como llega al mail).
  2. Opcional: «Activar edición», corregí textos (sobre todo el bloque amarillo «Motivo») y «Descargar HTML con marcas».
  3. O respondé por escrito indicando el nombre de la tarjeta (p. ej. «Marcar ausente», «Restituir titular…»).
